Here are selected research papers at the intersection of gaze/eye-tracking and LLMs for November 24, 2026.

Daily Concept: Gaze-based intention recognition

1. What is it?
Gaze-based intention recognition is the process of inferring a user's underlying goal or intended action from their eye movement patterns. In the context of large language models, this involves translating spatial and temporal gaze data into semantic prompts that guide model generation. It bridges low-level visual attention with high-level cognitive objectives.

2. How does it work?
Eye trackers capture raw gaze coordinates over time, which are segmented into sequences of fixations and saccades. A neural encoder transforms this spatiotemporal sequence into an embedding vector \(z\) that represents the user's latent intention. This embedding is then projected into the soft prompt space of a language model, acting as a conditioning vector \(P = W z\) where \(W\) is a learned projection matrix. The LLM then generates text or actions conditioned on both this gaze-derived prompt and any explicit textual input.

3. Why does it matter?
This technology enables proactive AI systems that can assist users before they explicitly articulate a request. It is particularly valuable for accessibility, allowing individuals with motor impairments to interact with LLMs using only their eyes. Furthermore, grounding language models in gaze data provides a rich multimodal signal that helps resolve ambiguities in context, leading to more accurate and context-aware generation.

4. Key insight
Human gaze patterns serve as an implicit, continuous prompt that reveals cognitive intent before verbalization occurs.

Paper Summaries

Persona Lenses: What Makes a Vision-Language Model See Through Its Persona's Eyes?

Authors: Yoonho Shin
arXiv: 2611.25508v1

Summary

1. Research Question
How can we effectively make a vision-language model simulate the gaze behavior of a specific persona on a web page? The paper investigates how different prompt engineering and model intervention strategies influence persona-driven gaze simulation.

2. Positioning
Existing vision-language models can simulate user gaze on web pages but simply inserting a persona description into the prompt only partially influences the resulting scanpath. This work fills the gap by systematically measuring how much a single persona attribute affects gaze and by introducing methods to better align model attention with persona characteristics. It explores the trade-offs between model scale and prompt-based interventions for accurate gaze prediction.

3. Key Contribution
The main contribution is the introduction of three persona lenses that mediate how a vision-language model processes a web page to generate gaze predictions. These include a text lens for generating persona-specific attention descriptions, a pixel lens for highlighting interest regions, and a weight lens using a dwell reward to maintain natural scanpaths. The paper also provides a comparative analysis of these lenses across different model scales to determine their relative effectiveness and robustness.

4. Methodology
The authors evaluate the lenses using Qwen3-VL models of 4B and 32B parameters and a 9B model on both generated and live web pages. They measure the difference in simulated gaze between MatrAIx personas that differ by a single attribute to assess the impact of each lens. The three lenses are compared against each other and against the baseline performance of the larger 32B model without any lens intervention.

5. Limitations
The text lens is not robust to profile changes that should not logically alter gaze behavior. The pixel lens provides weaker persona separation, suggesting that visual highlighting alone is insufficient to fully capture persona-driven attention. Additionally, smaller models require these lenses to achieve persona separation, whereas larger 32B models can do so with the base prompt alone, limiting the general applicability of the lenses for high-parameter models.

6. Critical Evaluation
The work provides a highly relevant exploration of controllability in LLM-driven gaze simulation by treating persona influence as a modular lens. A major strength is the nuanced comparison between prompt engineering techniques and model scaling, offering practical insights for cost-effective deployment. However, the reliance on specific Qwen model variants raises questions about cross-architecture generalization, and the evaluation of natural scanpath generation in the weight lens could benefit from deeper behavioral validation against human eye-tracking data.
